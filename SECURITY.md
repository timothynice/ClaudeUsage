# Security Policy

If you discover a security issue, please report it privately by opening a GitHub
Security Advisory at:

https://github.com/<OWNER>/<REPO>/security/advisories/new

Please include:

- Steps to reproduce
- Expected and observed behavior
- Any logs or request/response samples (redact secrets)
- Swift / macOS version

We will acknowledge reports within 7 days and share a resolution plan during
triage.
